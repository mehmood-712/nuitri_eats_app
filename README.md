# Nutrition Eats 🥗📱

**Nutrition Eats** is a cross-platform Flutter application designed to help users plan, calculate, and track their daily nutritional intake specifically when dining out or ordering from restaurants. 

Eating out often makes trackable meal planning difficult due to hidden calories and complex menu compositions. Nutrition Eats bridges this gap by offering precise restaurant meal planning, customizable macro tracking, and quick nutritional calculations.

---

## ✨ Features

- **🍽️ Restaurant Meal Planning**: Browse menus or input custom dish selections to construct balanced meals tailored to your diet goals.
- **📊 Real-time Macro & Calorie Calculation**: Instantly compute total calories, macronutrients (Protein, Carbs, Fats), and micronutrients for single dishes or combined meals.
- **⚙️ Custom Ingredient Adjustments**: Add or remove toppings, dressings, and sides to see how modifications affect your overall nutritional intake.
- **🎯 Personalized Nutrition Targets**: Set custom calorie and macro goals (e.g., Keto, High-Protein, Low-Carb) and track how restaurant meals fit into your daily budget.
- **❤️ Favorites & Saved Meals**: Save your go-to restaurant orders and custom combinations for fast logging in the future.
- **⚡ Fast & Modern UI**: Built with Flutter for a smooth, responsive, and intuitive cross-platform experience.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

Ensure you have the following installed on your development machine:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (version `>=3.0.0`)
- [Dart SDK](https://dart.dev/get-started/sdk)
- [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/) with Flutter extensions installed
- An Emulator or physical device (iOS / Android) for testing

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/nutrition-eats.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd nutrition-eats
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the app:**
   ```bash
   flutter run
   ```
